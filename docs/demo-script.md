# StudioOps Demo Script

1. Open the app and submit a sample brief.
2. Explain that the agent plans research before calling the web search API.
3. Show the progress states: brief analyzed, research plan created, search completed, synthesis in progress.
4. Display the final report sections: summary, comparable titles, market signals, production intelligence, risks, next steps, sources.
5. Highlight source provenance and evidence-based recommendations.
